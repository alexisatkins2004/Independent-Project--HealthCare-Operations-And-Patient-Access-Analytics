# Independent-Project--HealthCare-Operations-And-Patient-Access-Analytics
An end-to-end Power BI project analyzing healthcare operations, provider performance, patient access, and financial outcomes. Built progressively across the Microsoft PL-300 certification curriculum to demonstrate practical Power BI skills through a real-world healthcare analytics solution.

# Seattle Grace Health Network Operations Analytics

## Project Overview 

This project develops an end-to-end Power BI analytics solution for a fictional outpaitent healthcare network. The solution will track healthcare operations, provider performance, patient access, and financial outcomes. 

The project is being developed incrementally across the full Power BI analytics lifecycle: data preparation, dimensional modeling, DAX, report design, advanced analytics, security, and deployment. 

## Current Project Stage 

Phase 1: Data Preparation Using Power Query

## Business Questions 

- Which clinics experience the longest patient wait times?
- What factors contribute to cancellations and no-shows?
- How effectively is provider capacity being used?
- Which departments and services generate the strongest margins?
- How do operational performance and patient satisfaction relate?
- Which departments are falling below their monthly budgets?
- How do patient wait times impact satisfaction scores?

## Data Sources

- Monthly appointment CSV files
- Patient Excel workbook
- Provider CSV file
- Service CSV file
- Nested clinic JSON file
- Department budget Excel workbook
